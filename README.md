# Bo Liang — Personal Homepage

A responsive single-page personal portfolio built with vanilla HTML, CSS and
JavaScript — no frameworks, no build step.

**Live site:**&#8203; https://bob-ai-a.github.io

## Sections

- About — short self-introduction
- Education — BSc Data Science and Big Data Technology, Xi'an Jiaotong-Liverpool University (2023–2028, expected)
- Skills — programming, data & machine learning, tools, languages
- Projects — selected coursework and competition projects
- Contact — email and GitHub

## Features

- Responsive layout (desktop / tablet / mobile)
- Scroll-spy navigation highlighting the active section
- Smooth scrolling and a back-to-top button
- Zero external dependencies (no CDN, no third-party libraries)

## Tech Stack

- HTML5 — semantic markup
- CSS3 — custom properties, flexbox, grid
- Vanilla JavaScript (ES6+, IntersectionObserver)

## Run Locally

Clone the repository and open index.html in any modern browser — no build
tools or package manager required.

## Deployment

Hosted on GitHub Pages, deployed from the main branch (repository root).
HTTPS is enforced.
